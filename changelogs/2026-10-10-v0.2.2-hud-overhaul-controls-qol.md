# M.O.B. (Motors on Boost) — Release Notes v0.2.2

- **Release Date**: October 10, 2026
- **Version**: `0.2.2`
- **Build**: `Build 5`
- **Channel**: Alpha
- **Target Platform**: HTML5 / WebGL 2.0 (Heaps.io 2.1.0, Haxe 4.3.7)

---

## Overview

Version **0.2.2** delivers a comprehensive in-game HUD visual overhaul, limited and regenerating Nitrous Boost mechanics, configurable steering sensitivity controls, independent 3D render scaling decoupled from crisp 2D UI text, responsive UI layout with options menu scrolling, options tab collision fixes, connected graphics engine settings, and frosted glass touch controls with vector iconography.

---

## Key Highlights & Systems Overhaul

### 1. In-Game HUD Overhaul (`InGameHUDView.hx`)
- **Top-Left Angled Telemetry & Minimap Cluster**:
  - Digital speedometer with speed readout in KM/H, active transmission gear (`[G1]` - `[G6]`), and animated `[DRIFTING]` badge.
  - Lap counter (`LAP 1/3`) and high-precision race timer (`MM:SS.MS`).
  - Procedural circuit minimap projecting track spline geometry with road boundaries, track center line, and real-time glowing player position dot with directional heading vector tick.
- **Top-Center Curved Tachometer Arc**:
  - Radial tick markers with dynamic arc sweep tracking engine flywheel RPM (1,000 to 8,000 RPM).
  - Smooth cyan-to-amber-to-redline gradient arc fill with digital RPM readout.
- **Bottom-Center Curved Nitro Arc Gauge**:
  - Radial electric ribbon gauge displaying remaining nitrous capacity.
  - Procedural dual-layer flame icon with glowing inner core that turns fiery orange when boost is active.
  - Numerical percentage readout (`100% NITRO`) and depletion warning states.
- **Top-Right Performance Counter**:
  - Discreet, crisp real-time FPS counter.

### 2. Limited & Regenerating Nitrous Boost (`CarPhysics.hx`)
- **Capacity & Consumption Rates**:
  - Maximum fuel reservoir: `boostFuel = 1.0` (100%).
  - Active drain rate: `BOOST_DRAIN_RATE = 0.25 / s` (4.0 seconds of sustained boost).
  - Passive recharge rate: `BOOST_RECHARGE_RATE = 0.10 / s` (10.0 seconds from empty to full).
- **Auto-Cutoff & Acceleration Integration**:
  - Nitrous automatically cuts off when `boostFuel <= 0.0`.
  - Propulsion equations apply forward surge and motion blur only while fuel remains.

### 3. Granular Steering Sensitivity Setting (`ControlsOptionsPanel.hx`, `SaveSystem.hx`, `InputController.hx`)
- **Granular 2% Step Adjustment**:
  - Scalable from 0% to 100% in 2% increments (0.02 step size), allowing fine-tuned control over steering responsiveness.
  - Directly scales keyboard digital rack turn-in rate and gamepad analog stick deflection.
- **Save System Schema v4 (`SaveSystem.hx`)**:
  - Upgraded persistence key to `mob_motors_on_boost_save_v4` (`SAVE_VERSION = 4`).
  - Added `steerSensitivity: Float` (default `1.0`) with automatic forward migration from v1, v2, and v3 saves.

### 4. Decoupled 3D Render Scale from 2D UI Resolution (`PostProcessRenderer.hx`, `GraphicsManager.hx`)
- **Independent 3D Rendering Pass**:
  - 3D scene renders to a dedicated offscreen texture buffer scaled by `renderScale` (0.50x to 1.50x) via `PostProcessRenderer.hx`.
  - Heaps canvas and 2D scene backbuffer stay at native 1:1 window resolution, ensuring all 2D text, HUD elements, and menu typography remain pin-sharp at any 3D quality setting.
- **Connected Graphics Engine Settings**:
  - Lighting presets modulate ambient scene illumination (`ambientLight`) and sun tinting via `h3d.scene.fwd.LightSystem`.
  - Multi-sample antialiasing presets configured via `Engine.ANTIALIASING`.

### 5. UI Layout, Scrolling & Clipping Fixes (`OptionsView.hx`, `GraphicsOptionsPanel.hx`, `CardBackplate.hx`)
- **Options Tab Collision Resolved**:
  - Reduced `BACK_BUTTON_WIDTH` from `260.0` to `100.0`, eliminating hitzone overlap between the Back button and the "GRAPHICS" tab.
- **Viewport Scrolling in Graphics Options**:
  - Added vertical scrolling (`scrollOffset`, `maxVisibleRows`) with visual scroll indicator arrows and mouse wheel support, preventing options from clipping off-screen on low-resolution displays.
- **Adaptive Card Sizing**:
  - Dynamic height calculation in `CardBackplate.hx` preventing dialog clipping across various viewport aspect ratios.

### 6. Frosted Glass Touch Controls Aesthetic (`TouchControlsHUD.hx`)
- **Procedural Vector Iconography**:
  - Procedural vector icons drawn directly on canvas: flame icon for Nitro, accelerator pedal for Gas, ventilated disc brake with red caliper for Brake, and drift arc for Handbrake.
- **Frosted Glass Styling**:
  - Translucent button plates with glowing cyan highlights, active press glow states, and persistent resolution-aware anchoring.
