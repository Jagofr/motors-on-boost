# Release v0.6.1 (Build 0014) — Cross-Device LAN Relay, Invite Code Flow & Touch Offset Steppers

**Release Date:** 2026-11-15  
**Milestone:** Cross-Device LAN/WAN Multiplayer Reliability, Host-or-Join Invite Code UX & Touch-Only Layout Customization

## Summary
Upgraded multiplayer networking and configuration usability for multi-device mobile/desktop play: replaced WebSocket-only transport with a hybrid WebSocket + HTTP POST `/relay.ashx` bridge supported on both IIS (`web/relay.ashx`) and Node (`server/socket-relay.js`), added a "Host or Join" screen with direct Invite Code entry and automatic join retries/timeouts, and replaced single-direction touch cycling with a 2-column `- 10` / `+ 10` and `- 5%` / `+ 5%` touch stepper grid.

---

## Added
- **Host or Join Menu & Direct Invite Code Entry (`src/ui/views/multiplayer/MultiplayerMenuView.hx`, `src/ui/components/CardBackplate.hx`, `src/ui/components/UIEnums.hx`, `src/net/MultiplayerManager.hx`)**:
  - Added `UIState.MultiplayerMenu` between `MainMenu` (`MULTIPLAYER LOBBY`) and `MultiplayerLobby` with selectable **HOST A MATCH** and **JOIN BY INVITE CODE** cards.
  - Implemented `MultiplayerManager.extractRoomCode()` accepting either raw 6-character codes (`X5VC8D`) or full `?room=<CODE>` URLs, plus capture-phase DOM `keydown`/`paste` listeners and tap-to-prompt input inside `MultiplayerMenuView`.
- **Cross-Device IIS & Node Relay Endpoints (`web/relay.ashx`, `server/socket-relay.js`)**:
  - Added zero-dependency ASP.NET `MobSocketRelayHandler` (`web/relay.ashx`) supporting shared room state across HTTP JSON `POST /relay.ashx` and WebSocket requests across both ports (`:443` and `:16443`).
  - Upgraded `server/socket-relay.js` (`attachSocketRelay`) so Node servers accept both WebSocket upgrades (`/ws`, `/relay.ashx`) and HTTP `POST /relay.ashx` polling against the same `rooms` registry.
- **Resilient Client Join Handshake & Background-Tab Host Sync (`src/net/MultiplayerManager.hx`, `src/Main.hx`)**:
  - Added `MultiplayerManager.update(dt)` (`JOIN_RETRY_INTERVAL = 0.8s`, `JOIN_TIMEOUT_SECONDS = 8.0s`) and a `400ms` background visibility timer so stalled joins fail cleanly back to `Disconnected` instead of hanging indefinitely on `"Joining room..."`, while throttled Host tabs keep broadcasting world snapshots (`broadcastHostWorldSnapshot`) on incoming validated packets.
- **Touch-First 2-Column Offset & Scale Stepper Grid (`src/ui/views/options/ControlsOptionsPanel.hx`, `src/ui/ControlDiagrams.hx`, `src/ui/views/options/OptionsView.hx`)**:
  - Added dedicated `- 10` / `+ 10` (`-100 px` to `+100 px`) and `- 5%` / `+ 5%` (`50%` to `150%`) stepper buttons (`remapDecrInteractives`, `remapIncrInteractives`) across all 11 touch customization slots in a 2-column × 6-row grid plus `RESET DEFAULT LAYOUT`.
  - Updated `ControlDiagrams.drawTouchLayout(?ts)` to preview active `TouchSettings` offsets/scale in diagram mode and wired `OptionsView.onTabChanged` to redraw tab highlight capsules immediately on tap.

## Changed
- **Hybrid WebSocket → HTTP Relay Transport (`src/net/SocketTransport.hx`, `web/sw.js`)**:
  - Updated `WebSocketTransport` to connect via `/relay.ashx` with automatic failover within `1000ms` (or immediate rejection) to HTTP `POST /relay.ashx` polling (`60ms` interval), reserving `BroadcastChannel` for unreachable/offline contexts (`2500ms` join timeout).
  - Updated PWA service worker cache key to `mob-motors-on-boost-v0-6-1` and bypassed caching on `relay.ashx` and `/ws` requests.
- **Automated Verification (`tests/core/TestVersion.hx`, `tests/net/TestMultiplayer.hx`, `tests/ui/TestTouchControls.hx`, `aitests/run-playwright-tests.js`)**:
  - Added unit coverage for `extractRoomCode`, join retry/timeout recovery, negative/positive touch offset steppers, and updated Playwright Scenario 3 & Scenario 6 for touch steppers, `/relay.ashx` WS+HTTP interoperability, and invalid-room error handling.
