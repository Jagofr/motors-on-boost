# Changelog — v0.7.0 (Build 0015)

**Date:** 2026-11-16
**Milestone:** Complete WebGPU (`hlwgpu` + `xgpu` + `hlwindow`) & Ash Wasm32 Rewrite

## Architectural Changes
- **Removed Heaps.io (`heaps` / `format`) Dependency Completely:**
  - Replaced `h3d.Vector` / `h3d.Matrix` with pure Haxe Z-up right-handed math and Structure-of-Arrays GPU staging (`src/math/Vec3.hx`, `src/math/Mat4.hx`, `src/math/SoABuffer.hx`) enforcing WGSL 16-byte `std140`/`std430` alignment and WebGPU `[0, 1]` depth projection.
  - Replaced `h3d.scene.*` / `h3d.prim.*` with platform-agnostic scene graph & primitive descriptors (`src/graphics/SceneGraph.hx`, `src/graphics/Primitives.hx`).
  - Replaced `hxd.Key` / `hxd.Pad` with `src/input/InputKey.hx` and `src/input/GamepadDevice.hx` wired to `hlwindow` 0.3.2 (`window.Event`, `window.KeyCode`, `window.Gamepad`).

- **Custom Stateless WebGPU Renderer & WGSL Compute Shaders:**
  - Added `src/graphics/shaders/TrackComputeShader.hx`: WGSL `@compute @workgroup_size(64)` generating Circuit roadbed, asphalt ribbon, and double-sided Armco guardrails directly into GPU storage/vertex/index/indirect buffers rendered via `renderDrawIndexedIndirect`.
  - Added `src/graphics/shaders/SkyShader.hx`: fullscreen atmospheric twilight gradient shader with solar disc bloom.
  - Added `src/graphics/shaders/SceneLitShader.hx`: forward lit shader consuming 96-byte `InstanceData` storage arrays, procedural anti-aliased `SandboxMap` cyber-grid, track surface procedural details, clearcoat Fresnel, and emissive vehicle lights.
  - Updated `src/graphics/RadialBlurShader.hx`, `src/graphics/PostProcessRenderer.hx`, `src/graphics/GraphicsManager.hx`, and created `src/graphics/WebGpuRenderer.hx` using async pipeline compilation (`createComputePipelineAsync`, `createRenderPipelineAsync`) via `ash-future` fibers.

- **240 Hz Physics & World Preservation:**
  - Preserved `CarPhysics`, `SuspensionSolver`, `DrivetrainSolver`, `TireSlipSolver`, `SplineMath`, `ChaseCamera`, `Track`, `SandboxMap`, `TrafficSystem`, and Oimo rigid-body collision logic while migrating all math/scene bindings to WebGPU.

- **HTML5/CSS3 DOM UI Overlays & SharedArrayBuffer `WebBridge`:**
  - Replaced bitmap/Canvas2D Haxe UI rendering on web with responsive glassmorphism HTML5/CSS3 overlays (`web/ui-overlay.css`, `web/ui-overlay.js`, `z-index: 1`, `pointer-events: none` containers) synchronized at zero copy with `src/core/WebBridge.hx` (128 KB pinned SPSC ring & telemetry mailbox inside Wasm shared memory).
  - Updated `AudioManager`, `SaveSystem`, `AssetPreloader`, `SocketTransport`, and `MultiplayerManager` to bridge cleanly via `WebBridge` (preserving `InMemoryRelayHub` for headless unit suites).
  - Exposed synchronous `window.app` JS facade for `MOBOrientationGate` and automated E2E inspection.

- **Ash Wasm Build & IIS Deployment:**
  - Configured `compile.hxml` (`-hl web/game.hl -D wasm`) and Ash Wasm32 (`wasm32-wasip1-threads` with `ASH_WASM_FIBERS=1`) -> `web/game.wasm`, alongside `xgpu.wasm` and `xwindow.wasm`.
  - Updated `web/index.html` with pre-warmed `MessageChannel` worker pool (`thread.js` / `worker.js`), `web/web.config` with `.wasm`/`.mjs` MIME types and `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy` headers for `SharedArrayBuffer`, and bumped PWA service worker `web/sw.js` to `v0.7.0`.
