# Release v0.6.0 (Build 0013) — Peer-to-Peer Client/Server Lobby Multiplayer

**Release Date:** 2026-11-15  
**Milestone:** Peer-to-Peer Client/Server Architecture, Invite Links & Host-Authoritative Validation

## Summary
Introduced a lightweight, zero-dependency peer-to-peer client/server multiplayer mode built on top of a stateless WebSocket socket relay (`/ws`). Joining players only need to open the Host's shareable invite link (`?room=<ROOM_ID>`) to join the Host's lobby and race together on either **Highway Circuit** or **Sandbox Proving Grounds**.

---

## Added
- **Stateless WebSocket Socket Relay (`server/socket-relay.js`, `server/multiplayer-server.js`, `aitests/server.js`)**:
  - Zero-dependency RFC 6455 WebSocket upgrade and frame codec mounted on `/ws`.
  - Manages only ephemeral room creation (`host_room`), peer connection attachment (`join_room`), packet forwarding (`relay_to_host`, `relay_to_peer`, `relay_broadcast`), and disconnect notifications without performing any game validation on the server.
  - Added `WebSocketTransport` (`src/net/SocketTransport.hx`) with automatic `BroadcastChannel('mob_p2p_relay')` fallback when served over pure static HTTP hosts without WebSocket upgrade support.
- **Host-Authoritative Validation Engine (`src/net/MultiplayerManager.hx`, `src/net/NetworkProtocol.hx`)**:
  - Host strictly validates incoming peer join requests (`WaitingInLobby` phase, exact `Version.NUMBER`, `MAX_PLAYERS = 8` capacity cap, callsign sanitization, sequential slot/color assignment).
  - Host owns match map selection (`Circuit` or `Sandbox`), computes staggered 2-column grid `SpawnSlot` positions on `startMatch()`, and validates every incoming `ClientInputPacket` (`NaN`/infinity rejection, speed clamping `[-25, 95] m/s`, anti-teleport delta capping, and active `IGroundProvider.enforceBoundaries` clamping).
- **Multiplayer Host/Join & Lobby UI & Remote 3D Vehicle Actors (`src/ui/views/multiplayer/MultiplayerMenuView.hx`, `src/ui/views/multiplayer/MultiplayerLobbyView.hx`, `src/entities/RemoteCarActor.hx`, `src/world/WorldManager.hx`, `src/ui/views/hud/InGameHUDView.hx`)**:
  - Added **MULTIPLAYER LOBBY** entry to the Main Menu (`MainMenuView`, `UIBuilder`, `UIManager`) opening the **Host or Join** selection modal (`UIState.MultiplayerMenu` / `MultiplayerMenuView`).
  - Supported both direct keyboard/paste/prompt Invite Code entry (`MultiplayerManager.extractRoomCode`) in **Join by Invite Code** and automatic `?room=` URL join inside `Main.activateMainSplash()`.
  - Built Lobby UI showing Role badge, Invite Code, Copy Invite Link button, selectable Highway Circuit & Sandbox Proving Grounds arena cards, live driver roster (`1..8` colored slots), and Host Start Match trigger.
  - Added live smoothed `RemoteCarActor` 3D chassis/wheel transforms, bumper-to-bumper contact separation, and colored peer minimap dots.
- **Automated Verification (`tests/net/TestMultiplayer.hx`, `aitests/run-playwright-tests.js`)**:
  - Added headless `utest` suite validating Host rejections, capacity limits, map authority, and anti-cheat clamping.
  - Added Playwright Scenario 6 testing real two-context WebSocket invite-link join, map switching across both arenas, match start, and live vehicle replication.
