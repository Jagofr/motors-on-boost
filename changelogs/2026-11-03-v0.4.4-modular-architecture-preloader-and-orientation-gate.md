# Release Notes: v0.4.4 (Builds 0008–0010)

**Release Date:** November 3, 2026  
**Target Platform:** WebGL / HTML5, Desktop & Mobile Browsers (Chrome, Edge, Safari)  
**Compilation Builds:** `0008` – `0010`  

---

## Overview

Milestones **v0.4.2 – v0.4.4** represent the complete architectural modularization, boot sequence hardening, UI flow expansion, and multi-device E2E verification effort across **M.O.B. (Motors on Boost)**. Every core module was refactored into cleanly decoupled packages with JSDoc-compatible API documentation, a silent background preloader was introduced to eliminate boot flashing, mobile/tablet portrait blocking was enforced, and full Playwright automated tests were established for Keyboard, Gamepad, and Multi-Touch profiles.

---

## Key Highlights & Architectural Changes

### 1. Modular Architecture & Configuration Extraction (`src/config/`, `src/core/`, `src/world/`)
- **Centralized Configuration Schemas (`src/config/GameConfig.hx`, `src/config/WorldConfig.hx`)**:
  - Extracted hardcoded gameplay, camera, intro timing, virtual resolution, skybox, track, sandbox terrain, and traffic parameters into typed immutable configuration structures with clean factory defaults (`GameConfig.getDefault()`, `WorldConfig.getDefaultTrack()`, `WorldConfig.getDefaultSandbox()`, `WorldConfig.getDefaultTraffic()`).
- **Scene & Boot Orchestrators (`src/world/WorldManager.hx`, `src/core/AssetPreloader.hx`, `src/core/IntroController.hx`)**:
  - Extracted 3D world construction, map switching, lighting, post-process radial blur, and showcase camera logic out of `src/Main.hx` into `WorldManager`.
  - Implemented comprehensive `@jsdoc` / Haxe doc-comments across `src/` and synchronized `docs/DOCS.md` and `docs/API_REFERENCE.md`.

### 2. Zero-Flash Boot Sequence & Silent Background Preloading (`src/core/AssetPreloader.hx`, `src/core/IntroController.hx`)
- **Publisher / Engine / Disclaimer Flow**:
  - Structured the sequential boot pipeline (`IntroState.Studio` -> `Engine` -> `Disclaimer` -> `Complete`) before initializing or revealing the 3D scene (`rendered3DWhileIntro == 0`).
- **Progress-Bar-Free Background Preloader**:
  - `AssetPreloader` decodes UI icons, splash artwork, and scene resources asynchronously in memory behind the branding screens and cleanly holds `IntroState.Disclaimer` until background warming finishes without displaying a progress bar.

### 3. Map Select, Pause Restart & Save/Resume Flows (`src/ui/views/mapselect/MapSelectView.hx`, `src/ui/views/pause/PauseMenuView.hx`)
- **Dedicated Map Select Screen**:
  - Replaced legacy menu map buttons with `MapSelectView` supporting `MapMode.Circuit` (Closed Highway Loop) and `MapMode.Sandbox` (Proving Grounds) with live card selection via keyboard, gamepad D-pad, and touch tap.
- **Pause Restart & Active Run Persistence**:
  - Added immediate `RESTART MAP` reset from `PauseMenuView` on both Circuit and Sandbox maps, alongside persistent active run restoration (`RESUME SAVED RACE` in `MainMenuView`).

### 4. Mobile & Tablet Portrait Orientation Gate (`web/index.html`, `src/Main.hx`)
- Enforced landscape-only play on mobile and tablet viewports:
  - Attempts native `screen.orientation.lock('landscape')` when supported on user gesture / boot.
  - Displays a clean full-screen portrait lock overlay (`#rotate-device-overlay`) with landscape rotation prompt fallback and automatically pauses physics/simulation while in portrait orientation.

### 5. Multi-Input 5-Scenario Playwright & Unit Test Suites (`aitests/run-playwright-tests.js`, `tests/`)
- Built 5 end-to-end verification scenarios covering boot gating, all Main Menu buttons, Options tabs, Map Select, Pause Restart, Save/Resume, and steering accuracy executed identically across **`keyboard`**, **`gamepad`**, and **`touch`** virtual HUD profiles plus mobile/tablet orientation gate tests.
- Added Haxe unit suites in `tests/core/TestBootAndConfig.hx` and `tests/ui/TestFullMenuAndOptionsFlow.hx`.
