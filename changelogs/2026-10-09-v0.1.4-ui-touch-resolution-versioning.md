# M.O.B. (Motors on Boost) — Release Notes v0.1.4

- **Release Date**: October 9, 2026
- **Version**: `0.1.4`
- **Build**: `Build 148`
- **Channel**: Alpha
- **Target Platform**: HTML5 / WebGL 2.0 (Heaps.io 2.1.0, Haxe 4.3.7)

---

## Overview

Version **0.1.4** addressed cross-screen version tracking, mobile multi-touch virtual controls, high-DPI display text rendering, decoupled UI and 3D rendering resolutions, and seamless save data schema migration.

---

## Key Highlights & Systems Implemented

### 1. Centralized Version Tracking (`Version.hx`)
- Single source of truth for semantic versioning, build compilation counter, and release tagging.
- Persistent version and build number badges integrated across all 5 core application UI screens:
  - Trademark Disclaimer Screen
  - Title Splash Screen
  - Main Menu Footer
  - Options Card Header
  - Credits Screen

### 2. Mobile Multi-Touch Virtual Driving Controls (`TouchControlsHUD.hx`)
- Camera-aware coordinate projection mapping canvas buffer pixels into 2D scene space through `s2d.interactiveCamera.eventToCamera()`.
- Zero-allocation scratch instances eliminating per-touch garbage collector pressure.
- Euclidean distance-to-center evaluation for action capsules.
- Browser `touchcancel` event listener providing fail-safe resets on system gesture interruptions.

### 3. High-DPI Display Font Rendering (`FontManager.hx`)
- Fixed missing `baseLine` property on TrueType font descriptors, restoring crisp text rendering across Apple Retina and high-DPI displays.

### 4. Decoupled 3D Graphics & UI Resolution Scaling
- Independent 3D rendering resolution scaling (`renderScale`: 0.25 to 4.0) separated from UI layout dimensions.
- Configurable 2D UI resolution presets (`720p`, `1080p`, `1440p`, `2160p`, `Native / Match Window`) using Heaps `AutoZoom`.

### 5. Save System v2 Schema Migration (`SaveSystem.hx`)
- Upgraded active persistence key to `mob_motors_on_boost_save_v2`.
- Automated forward migration for records originating from `mob_motors_on_boost_save_v1` and legacy prototype keys.
