# M.O.B. (Motors on Boost) — Release Notes v0.1.1

- **Release Date**: October 6, 2026
- **Version**: `0.1.1`
- **Channel**: Alpha
- **Target Platform**: HTML5 / WebGL 2.0 (Heaps.io 2.1.0, Haxe 4.3.7)

---

## Overview

Version **0.1.1** finalized project rebranding from the initial working title to **M.O.B. // MOTORS ON BOOST**, migrated client persistence keys, and resolved PWA icon caching paths.

---

## Key Changes

### 1. Branding Standardization
- Rebranded application title, banners, UI views, splash screens, documentation, and web manifest to **M.O.B. // MOTORS ON BOOST**.
- Standardized in-game credits and attribution screens.

### 2. Client Persistence Key Migration (`SaveSystem.hx`)
- Migrated primary browser `localStorage` persistence key to `mob_motors_on_boost_save_v1`.
- Added backward-compatible fallback for prototype saves stored under `burnout_overdrive_save_v1`.

### 3. PWA Service Worker Asset Resolution (`sw.js`)
- Corrected PWA service worker asset paths in `sw.js` to target `./icons/icon-192.png` and `./icons/icon-512.png`.
- Added IIS `web.config` for static WebP and JSON MIME type mappings.
