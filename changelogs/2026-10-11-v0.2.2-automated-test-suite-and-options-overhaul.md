# M.O.B. (Motors on Boost) — v0.2.2 Test Suite & Options Overhaul

**Release Date:** 2026-10-11  
**Target Build:** Haxe 4.3.7 / Heaps.io 2.1.0 (WebGL / JS PWA)  
**Modules Covered:** Core Architecture, Physics, Rendering, UI, Input, Audio, Entities, Camera, Save, Automation  

---

## Executive Summary
This release implements a comprehensive dual-tier testing and quality-assurance infrastructure for M.O.B. (Motors on Boost):
1. **Headless Unit Test Suite (`tests/`)**: Built on `utest` (1.13.2) and compatible with the VSCode `Haxe Test Explorer` plugin, featuring 197 assertions across 12 test fixtures covering every module of the codebase. Executes headlessly in under 0.10s via Node.js with zero memory leaks.
2. **Automated Browser Visual/Programmatic Testing Suite (`web/test-suite.html` & `tests/run-browser-tests.js`)**: An interactive and headless browser test runner using Microsoft Edge and Chrome DevTools Protocol (CDP), testing 6 key scenarios including startup resolution, decoupled 2D UI vs 3D rendering, graphics option dependency locking, persistent steering sensitivity, and touch control layout customization.
3. **Graphics Options Hierarchy & Dependency Graying Out**: Dependent settings (Shadow Resolution, Anisotropy, Anti-Aliasing Multiplier, and Reflection Level) automatically disable, display `[DISABLED]`, and reject user modifications when their parent feature is disabled.
4. **Dedicated Touch Controls Tab**: Added a 5th tab to the Options View featuring a procedural vector diagram in Default mode and fine-grained button offset/scale customization in Custom mode with a 1-click Reset to Defaults.

## Dual-Tier Test Suite Architecture

### 1. Headless Unit Test Suite (`tests/`)
- **Framework**: `utest` + `test-adapter` + `vshaxe.haxe-test-adapter`.
- **Target**: Compiled to `bin/test.js` and executed via `tests/node-runner.js`.
- **Fixtures (12 Suites, 200 Assertions, 100% Pass Rate)**:
  - `TestVersion`: Semantic version display, short string, and component checks.
  - `TestSplineMath`: Catmull-Rom spline calculations, projection clamping, segment indexing.
  - `TestCarConfig`: Configuration defaults and JSON serialization roundtrips.
  - `TestCarPhysics`: Raycast suspension forces, anti-roll bars, tire slip angles, drift triggers, braking deceleration, throttle acceleration, and nitrous fuel drain/recharge.
  - `TestSaveSystem`: Save schema v4 migration, default settings integrity, touch controls configuration persistence.
  - `TestInputController`: Device exclusivity, key mapping names, steer sensitivity, multi-touch register assignments.
  - `TestTrack`: Waypoint continuity, track widths, banking angles, segment counts.
  - `TestTrafficSystem`: Traffic agent state transitions and collision proximity thresholds.
  - `TestChaseCamera`: FOV dynamic scaling, trauma decay, camera lag smoothing.
  - `TestGraphicsOptions`: Hierarchy dependency locking (`isOptionDisabled`), row disabling text formatting, setting persistence.
  - `TestTouchControls`: Vector layout coordinates, multi-touch chord concurrency, custom offset application, sensitivity slider persistence.
  - `TestAudioManager`: Volume clamping, menu beeps, safe null-context fallback handling.

### 2. Browser Visual / UI Automation Suite (`web/test-suite.html`)
- **Architecture**: Embeds live game canvas via `<iframe>`, directly interfacing with `window.app`.
- **Automated Scenarios**:
  - **Scenario 1 (Trademark & Boot Resolution)**: Validates initial intro state, displays Trademark Disclosure screen, verifies disclaimer header and version text (`v0.2.2`), and verifies 1280x720 AutoZoom virtual baseline.
  - **Scenario 2 (UI vs 3D Render Scale Independence)**: Alters 3D `renderScale` (0.5x) and verifies 2D UI scale baseline remains untouched; alters UI resolution setting without degrading 3D render target.
  - **Scenario 3 (Graphics Options Dependency Locking)**: Cycles Shadow Quality to "Off" (disables Shadow Buffer), Mipmapping to `false` (disables Anisotropy), AA to "None" (disables AA Level), Reflections to `false` (disables Reflection Level), asserting `[DISABLED]` badges and blocked cycling.
  - **Scenario 4 (Global Input Sensitivity Slider)**: Validates persistent top sensitivity slider across Keyboard, Gamepad, and Touch tabs, stepping in 2% increments and synchronizing with `InputController.steerSensitivity`.
  - **Scenario 5 (Touch Controls Tab Customization)**: Validates Default mode vector schematic, Custom mode row repositioning, live `TouchControlsHUD` offset updates, and Reset to Defaults.
  - **Scenario 6 (In-Game Drive Simulation)**: Enters race mode, injects simulated throttle, steer, and nitrous boost inputs; validates forward acceleration (> 5 m/s), nitro depletion, and automatic recharge.

## File Changes Summary
- `src/Main.hx`: Exposed public getters for engine, scene, and core systems for automation testability.
- `src/save/SaveSystem.hx`: Extended `TouchSettings` typedef and implemented schema v4 migration.
- `src/ui/views/options/GraphicsOptionsPanel.hx`: Added `isOptionDisabled(idx)` and disabled row styling.
- `src/ui/views/options/ControlsOptionsPanel.hx`: Implemented persistent Steering Sensitivity slider and Touch tab support.
- `src/ui/views/options/OptionsView.hx`: Added `Touch` to `TAB_ORDER` and adjusted tab dimensions.
- `src/ui/components/TouchControlsHUD.hx`: Connected dynamic offsets and scale into layout updates.
- `src/ui/FontManager.hx`: Headless-safe fallback bitmap fonts without redundant macro calls.
- `tests/*`: 12 test fixtures, runner, and configuration files.
- `web/test-suite.html`: Interactive browser test dashboard.
- `test.hxml`: Added `-w -WDeprecatedEnumAbstract` to cleanly suppress third-party `utest` macro deprecation warnings; configured Node runner invocation.
- `tests/TestMain.hx`: Added modular argument and environment filter targeting (`shouldRun(moduleName, className)`), enabling single module (`physics`, `ui`, `input`, etc.) or single test class execution.
- `src/graphics/PostProcessRenderer.hx`: Dynamically allocated a matching `Depth24Stencil8` depth target when `renderScale != 1.0` to eliminate WebGL depth buffer dimension mismatch exceptions.
- `tests/run-browser-tests.js`: Streamed CDP console and exceptions to terminal; updated Edge headless arguments with isolated profile.
- `.vscode/tasks.json`: Added dedicated module tasks for Physics, UI, Input, Save, World, Entities, Camera, Audio, and Browser automation.
- `src/camera/ChaseCamera.hx`: Replaced extreme distance lag with bounded subtle pull-back (+0.85m), anchored velocity feedforward, and dynamic non-linear FOV expansion (65.0° - 77.0°, +3.5° boost) to prevent fisheye distortion.
